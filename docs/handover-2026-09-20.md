# 핸드오버 문서 — 홈 카드 리디자인 + 상단바 재정렬 + iOS 세이프 에어리어 (2026-09-20)

## 변경 요약

홈 화면 영상 카드를 제목 중심에서 "대회명/주제 배지 + 상대(또는 참가자) 헤드라인" 중심으로 리디자인하고, 영상 등록 폼의 진행일 자동완성·푸시 알림 문구를 손봤습니다. 이어서 상단 헤더 순서를 재정렬(로고 왼쪽, 나머지 오른쪽 정렬)하면서 "등록하기" 버튼을 햄버거 메뉴 안으로 옮겼고, 그 과정에서 깨질 뻔한 온보딩 튜토리얼과 모바일 레이아웃 버그를 함께 수정했습니다. 마지막으로 카드 날짜 텍스트 가독성과 iOS 홈 화면 설치 시 하단 내비게이션이 홈 인디케이터에 눌리는 문제를 표준 방식(safe-area-inset)으로 고쳤습니다. **세 커밋 모두 origin/main에 push 완료된 상태이며 작업 트리는 클린합니다.**

## 기능 사용 흐름

### 홈 화면 영상 카드
- 썸네일 좌상단: 대회 연결 영상이면 대회명 배지, 아니면 주제(정규운동 등) 배지
- 썸네일 우상단: 등록 3일 이내면 New 배지
- 썸네일 하단(그라데이션 위): 대진표에 상대가 정확히 연결된 경우 "vs 상대이름", 아니면 참가자 헤드라인("이름 외 N명") — 참가자가 여럿이면 항상 첫 번째 태그가 아니라 영상 id 기준으로 골고루 다른 사람이 대표로 뽑힘 (로딩마다 바뀌지 않고 영상별로 고정)
- 카드 하단: 날짜만 표시 (참가자 해시태그 목록은 제거됨)

### 영상 등록 (관리자, `/admin`)
- YouTube URL 입력 후 포커스를 벗어나면 제목 자동완성과 함께, 제목이 "YYMMDD ..." 형식이면 그 날짜로 진행일이 자동 채워짐 (아니면 어제 날짜로 대체)
- 등록 시 발송되는 푸시 알림은 "M월 D일 정규운동 영상이 업로드되었어요!" 형식 (영상 제목은 알림에 노출 안 됨)

### 상단바 / 메뉴
- 헤더: 로고(왼쪽) → 검색 → 알림 → 튜토리얼(?) → 햄버거(오른쪽 정렬)
- "영상 등록하기"는 햄버거 메뉴를 열면 홈/목록/캘린더 보기/주제별 보기/대회 기록 아래에 있음 (데스크톱 사이드바·모바일 슬라이드 패널 모두)

## 알려진 제약 / 유의사항

- **iOS 세이프 에어리어 실기기 미검증**: `viewport-fit=cover` + `env(safe-area-inset-bottom)`로 하단 내비게이션이 홈 인디케이터에 안 눌리게 처리했지만, Windows 개발 환경에서는 Playwright(Chromium/WebKit 모두)로 이 값을 재현할 수 없어(항상 0으로 계산됨) 실제 효과를 스크린샷으로 확인하지 못했습니다. **다음에 아이폰에서 홈 화면 아이콘으로 열어 하단바 여백이 자연스러운지 한 번 봐주세요.** 부족하면 `BottomNav.tsx`의 `paddingBottom` 값을 조정하면 됩니다.
- **대진표 상대 헤드라인은 아직 실사용 데이터가 없음**: "vs 상대이름"이 뜨려면 대진표에서 두 선수 중 정확히 한쪽만 "우리 팀"으로 표시돼 있어야 하는데, 현재 DB엔 그렇게 정확히 태깅된 매치가 하나도 없어 실제로는 항상 참가자 헤드라인 경로만 보임 (기능 자체는 정상 동작, 데이터가 쌓이면 자동으로 뜸).
- **온보딩 튜토리얼 5단계("등록하기")는 이제 햄버거 메뉴를 강제로 열었다 닫는 동작을 함**: `TutorialTour.tsx`가 `tutorial-open-sidebar`/`tutorial-close-sidebar` 커스텀 이벤트를 dispatch하고 `AppLayout.tsx`가 이를 구독해서 `sidebarOpen` 상태를 바꿉니다. 메뉴 UI를 다시 손볼 일이 있으면 이 이벤트 연결을 함께 확인할 것.
- **날짜 자동완성은 휴리스틱**: 제목 앞 6자리가 우연히 숫자 6개인 다른 케이스(대회명이 숫자로 시작하는 경우 등)에서는 의도와 다른 날짜가 채워질 수 있음 — 실데이터 317건 기준 6자리 접두사가 있는 131건 중 119건이 실제 날짜와 정확히 일치했고 나머지는 관리자가 이후 수동으로 고친 것으로 보이는 1~2일 오차였음. 자동완성이니 틀리면 등록 전에 고치면 됨.
