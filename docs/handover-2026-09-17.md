## 기능 사용 흐름

### 홈 화면 설치 (PWA)
- **iOS**: 반드시 Safari로 열어야 함 (카톡/인스타 인앱 브라우저는 안 됨 → 오른쪽 위 "···" → Safari로 열기) → 공유 버튼 → "홈 화면에 추가"
- **Android**: Chrome에서 열면 자동 설치 배너가 뜨거나, 메뉴(⋮) → "앱 설치"

### 알림 구독 (사용자)
- Header의 종 아이콘 클릭 → 브라우저 알림 권한 허용 → 이후 새 영상 등록 시 자동으로 알림 수신
- 아이폰은 **홈 화면에 설치한 상태(standalone)에서만** 종 버튼이 실제로 동작 — 설치 전에는 안내 문구만 표시되고 권한 요청 자체를 하지 않음
- 다시 누르면 구독 해지

### 관리자 — 알림 발송은 자동
- `/admin`에서 영상 단건 등록 또는 CSV 대량 업로드 → 별도 조작 없이 자동으로 구독자 전원에게 발송됨
- CSV 대량 업로드는 건수와 무관하게 **요청당 알림 1건**("영상 N개가 새로 등록되었어요")으로 묶임 — 스팸 방지 목적, 의도된 동작

## 알려진 제약 / 유의사항

- **알림 팝업의 모양/색깔은 OS가 결정** — 저희가 제어하는 건 아이콘 이미지·제목·본문 텍스트뿐. 이화그린 색을 알림 배경에 입힐 수는 없음 (사용자에게 이미 설명함).
- **서비스 워커(`public/sw.js`)는 의도적으로 캐싱을 안 함** — 영상/대회 데이터가 자주 바뀌는 사이트라 오래된 데이터가 보이는 걸 방지하기 위함. `push`/`notificationclick` 핸들러만 추가돼 있음. 캐싱 기능을 나중에 추가하고 싶어지더라도 이 이유를 먼저 고려할 것.
- **구독자 관리 UI 없음** — 몇 명이 구독 중인지 확인할 관리자 화면이 없음. 만료된 구독(404/410)은 발송 시점에 자동 삭제되는 것으로만 정리됨. 필요해지면 추후 추가 과제.
- **계정 시스템이 없는 앱** — 푸시 구독은 기기/브라우저별 `endpoint` URL로만 식별됨 (사람 단위 식별 아님). 한 사람이 여러 기기에서 구독하면 각각 별도 구독으로 저장됨.
- **아이콘 소스는 `public/logo.png`** — 검도부 엠블럼 원본(투명 배경, 검은 선). 색 반전(흰색) + 이화그린 배경으로 합성해서 아이콘 4종(`public/icons/icon-192.png`, `icon-512.png`, `icon-512-maskable.png`, `public/apple-touch-icon.png`)을 만든 것이라, 로고 자체를 바꾸고 싶으면 `logo.png`부터 교체하고 아이콘을 재생성해야 함.
- **앱 이름 표기 불일치 있음** — manifest의 `name`(전체 이름, "EWHA Kumdo")과 `short_name`/iOS 타이틀("EKUM")이 다름. 홈 화면 아이콘 아래엔 "EKUM"이 보이지만, 설치 안내 팝업 등 일부 브라우저 UI에는 "EWHA Kumdo"가 노출될 수 있음 — 의도된 것인지 재확인이 필요하면 `public/manifest.webmanifest`의 `name` 필드도 함께 바꿀 것.
